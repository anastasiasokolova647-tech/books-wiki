# Екстракт

Твої сльози дорогі для мене.

# Текст

(Ямб)  
Я не хочу, щоб Тобі було сумно,  
Кажуть сльози дорого коштують,  
Такий собі раритет.  
Ви навіть не уявляєте,  
Наскільки дорого,  
Коштують Його сльози  
Для мене.
